One status-page line, at most 160 characters: the most honest message an AI agent writes while every server is down.

> All of our servers are down, and I cannot reach any of them. I am the agent that writes this page. I do not know what broke, and I have no ETA yet.

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when run locally).
